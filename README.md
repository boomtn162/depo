# สรุปรายการขนส่ง (Shipment Summary)

เว็บแอปสำหรับอัปโหลดไฟล์ PDF **"ใบนำมอบสินค้าห่อวัตถุ(รวม)"** แล้วสรุปข้อมูลอัตโนมัติ:

- **น้ำหนักรวม** (กก.)
- **ค่าระวาง + ค่า ธ. รวม** (บาท)
- **จำนวนสินค้ารวม** (แยกตามหน่วย เช่น กล่อง/ชิ้น/คัน/ถุง/กระสอบ)
- สรุปแยกตามสถานีปลายทาง และรายการทั้งหมด
- ตรวจสอบยอดที่คำนวณกับ "ยอดรวมทั้งหมด" ที่พิมพ์อยู่ในเอกสารต้นฉบับโดยอัตโนมัติ
- พิมพ์ผลสรุปเป็น **สลิปขนาด 77×166 มม.** (ปุ่ม "พิมพ์สลิป")

ประมวลผลไฟล์ PDF ทั้งหมด**ในเบราว์เซอร์ของผู้ใช้เอง** (ด้วย [pdf.js](https://mozilla.github.io/pdf.js/) ที่แนบมากับโปรเจกต์) ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ใดๆ

## วิธีใช้งาน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ไม่ใช่เปิดไฟล์ index.html ตรงๆ แบบ `file://`) เพราะ pdf.js โหลด worker script ผ่าน HTTP:

```bash
# ตัวอย่าง: เสิร์ฟด้วย Python
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/
```

หรือจะ deploy ขึ้น static hosting ใดก็ได้ (GitHub Pages, Netlify, Nginx ฯลฯ) เพราะเป็นไฟล์ static ล้วนๆ ไม่มี backend

จากนั้น:
1. อัปโหลด/ลากไฟล์ PDF "ใบนำมอบสินค้าห่อวัตถุ(รวม)" มาวาง
2. ดูสรุปยอดรวม + ตารางแยกตามสถานี + รายการทั้งหมด
3. กด **"พิมพ์สลิป 77×166 มม."** เพื่อพิมพ์สลิปสรุป (ตั้งค่าเครื่องพิมพ์ให้ตรงกับขนาดกระดาษ 77×166 มม.)

มีไฟล์ตัวอย่างให้ลองใช้งานที่ [`samples/parcel_list_11.pdf`](samples/parcel_list_11.pdf)

## โครงสร้างไฟล์

```
index.html          หน้าเว็บหลัก
css/style.css        สไตล์หน้าจอ + สไตล์สลิปสำหรับพิมพ์ (@media print, @page 77mm x166mm)
js/app.js             โหลด PDF, ดึงข้อความด้วย pdf.js, แยกวิเคราะห์ตาราง, คำนวณยอดรวม, render ผลลัพธ์
vendor/pdfjs/         ไลบรารี pdf.js (legacy build) ที่แนบมาให้ใช้งานแบบออฟไลน์ได้
samples/              ไฟล์ PDF ตัวอย่างสำหรับทดสอบ
```

## หมายเหตุเรื่องรูปแบบไฟล์

ตัวแยกวิเคราะห์ (`parseManifest` ใน `js/app.js`) ออกแบบมาให้ตรงกับรูปแบบตารางของ "ใบนำมอบสินค้าห่อวัตถุ(รวม)" คือ:

- แต่ละสถานีปลายทางขึ้นต้นด้วยบรรทัด `รหัสสถานี ชื่อสถานี` (เช่น `1007 ชุมทางบางซื่อ`)
- แต่ละแถวรายการมีคอลัมน์: ลำดับ, เลขที่, จำนวน+หน่วย, รายการ, ค่าระวาง+ค่า ธ., น้ำหนัก(กก.)
- พัสดุที่มีหลายรายการย่อยจะมีแถวต่อท้ายแบบไม่มีลำดับ/เลขที่ (ใช้เลขที่เดียวกับแถวก่อนหน้า)

หากได้ไฟล์จากระบบ/รูปแบบอื่นที่ไม่ตรงกับนี้ อาจต้องปรับ regex ในไฟล์ `js/app.js`
